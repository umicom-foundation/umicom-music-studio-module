Captions in Umicom Music

Use the Captions page to prepare timed lyrics for a music video or performance. You can open an SRT file exported from Song and video plan, or paste timed captions from another editor. This does not generate vocals or change the audio arrangement.

  1. Select Creative workbench, then choose Captions.
  2. Paste SRT or plain WebVTT text, or enter the full path to a UTF-8 caption file and select Open SRT or WebVTT from path. Save an existing draft before approving replacement. Successful preparation displays editable SRT, whichever format you started with.
  3. Select Prepare captions. Enter a millisecond preview time and inspect the active text.
  4. Apply a positive or negative time shift, or enter an excerpt range and extract captions. Keep the zero-based timeline option selected for a new clip.
  5. Enter a new file path in your chosen folder. Select the SRT or WebVTT save button and wait for the completion message. Existing files are preserved.

For a complete example, limits and recovery steps, read the installed Framework guide Edit captions and prepare a shorter clip, also found at framework/docs/learning/caption-editing.html in the Applications checkout.

Captions are not saved with scene projects. Export before closing. The shared editor has one-step undo for prepared changes; manual edits require preparation again. It supports plain text without markup, up to 512 cues. It provides text preview and caption files, not transcription, playback or encoded video.

You can reopen exported WebVTT files. Cue timing and overlapping text are preserved; numeric labels are renumbered. The current reader rejects named labels, styles, positioning settings, notes and other metadata rather than dropping information. See the Framework guide for a supported WebVTT example.
