Umicom Music user guide: create notes and export audio

The Creative workspace contains the Framework-backed note editor. A note stores a pitch, start position, length and velocity. Velocity controls how strongly the note is played. Generic layout panels do not yet provide a full recording or playback engine.

Create a practice project

  1. Open the Creative workspace in Umicom Music Studio.
  2. Choose a project ID, such as practice-song, and a title. An ID is the stable name used to reopen that project in its current store.
  3. Choose Create new project. Read the result before adding notes.
  4. Set the duration and tempo, then save the project settings. Keep the first exercise short.

Do not assume every workspace is automatically durable. Check the selected storage and export work you need to keep. Opening a generic piano-roll or arranger layout does not establish that it has an audio executor.

Add, change and remove a note

  1. Open the note controls. Use a new note ID, for example note-1.
  2. Set the start to 0, length to 480 ticks, pitch to 69 and velocity to 80. A tick is a small time unit; these controls use 480 ticks per beat.
  3. Choose Add note. The project should contain one note.
  4. Change the pitch to 72 and choose Update note. Changing a field alone is not the same as applying the edit.
  5. Choose Undo and check the previous pitch, then Redo and check the new pitch.
  6. Choose Remove note to remove the selected ID. Add a new note when you want to continue.

Adding an existing ID is rejected. Use Update note to change that note, or choose another ID. The complete note range must fit inside the project duration.

Write an audio file

  1. Open the export controls and select WAVE output.
  2. Use Browse or enter a new absolute output filename in a folder you control.
  3. Choose Write a new export file and read the result.
  4. Open the resulting file in an audio player. The note renderer uses a simple sine-wave instrument; it is not a sampled instrument or a plugin host.

An export is a new file. Choose a different name if the destination already exists. Audio clips and arrangements have separate tools; the basic note export does not imply recording, mixing or every workstation feature is implemented.

Controls and expected results

ControlExpected result
Create / Open projectCreates a project or opens the chosen ID in the active store.
Add / Update / Remove noteChanges the Framework project only after validation.
Undo / RedoRestores the earlier or later committed edit.
Reload saved projectReads the store again; inspect any unsaved form edits first.
Generic layout command without an executorExplains that no audio or generation job started.

Check before relying on a session

Create a project, add a note, change it, undo, redo and export. Try adding the same ID twice and confirm the rejected operation leaves one note. Close a tool window and reopen it; controls in a closed view must not continue changing the project.
